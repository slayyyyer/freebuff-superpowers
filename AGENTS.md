## Superpowers

This project uses the freebuff-superpowers workflow pack. Skills are mandatory
procedures, not suggestions.

Before a non-trivial task, read `C:/Users/justin/.agents/skills/using-superpowers/SKILL.md` and follow the
skill it routes you to. The common ones:

- Goal is vague or the request has several readings → `C:/Users/justin/.agents/skills/brainstorming/SKILL.md`
- Multi-step change with an agreed approach → `C:/Users/justin/.agents/skills/writing-plans/SKILL.md`, then `C:/Users/justin/.agents/skills/executing-plans/SKILL.md`
- Adding or changing observable behavior → `C:/Users/justin/.agents/skills/test-driven-development/SKILL.md`
- Something is broken or inexplicable → `C:/Users/justin/.agents/skills/systematic-debugging/SKILL.md`
- Before saying the work is done → `C:/Users/justin/.agents/skills/requesting-code-review/SKILL.md`, then `C:/Users/justin/.agents/skills/verification-before-completion/SKILL.md`
- Writing a new skill → `C:/Users/justin/.agents/skills/writing-skills/SKILL.md`

Small fixes still get small process: skip brainstorming and planning, never skip
verification. If a long session has been compacted, re-read this block before continuing.
